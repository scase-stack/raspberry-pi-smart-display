# raspberry-pi-smart-display
A Raspberry Pi-based smart display that automatically launches a full-screen dashboard and displays real-time information from multiple data sources.

Features

Automatically launches the dashboard on startup

Displays live information using external APIs and web data

Runs in full-screen kiosk mode

Integrates Raspberry Pi hardware with a custom display interface

Housed in a custom-designed 3D-printed enclosure

Technologies

Raspberry Pi

Python

HTML/CSS/JavaScript

APIs and web scraping

Arduino

CAD / 3D Printing

How It Works

The Raspberry Pi boots directly into the dashboard and launches a browser in kiosk mode. The dashboard retrieves information from external APIs and web sources, processes the data, and displays it in an easy-to-read interface.

An Arduino was also incorporated into the system for additional hardware functionality.

Project Goals

The goal of this project was to combine software, hardware, and physical design into a single functional system. It provided experience with Raspberry Pi development, web interfaces, APIs, hardware integration, and CAD.
